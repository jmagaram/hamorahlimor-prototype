# English practice — teacher prototype

Click-through prototype of the teacher side of an English speaking-practice app. React + TypeScript + Vite, no backend: data is in memory, seeded with sample data, and resets on reload. Audio is faked.

```bash
npm install
npm run dev
```

- `CLAUDE.md`: project overview, naming, UI model, code layout.
- `docs/data-model.md`: entities and rules (source of truth).
- `docs/screens.md`: every teacher page.
- `prototype/teacher.html`: the original single-file prototype, kept as a behavior reference.
